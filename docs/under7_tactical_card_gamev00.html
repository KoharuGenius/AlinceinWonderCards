GAME RULES

  • 13枚のトランプ（A～K）を使用する2人対戦。先に2勝した方の勝利です。
  • 山札から1枚引いて場に伏せられます。場札がA～6の時だけ「Under 7」バッジが表示されます。
  • 手札から1枚選び、場札＋手札で勝負します。
  • 点数計算（バカラ方式）：
    A=1点、2～9=数字通り、10～K=0点。
    （合計の下一桁が9に近い方が勝ち）
  • ロイヤルペア（特殊判定）：
    場札と自分のカードが両方とも【J, Q, K】（絵札）の場合、通常点数に無条件勝利！
    ※10は0点ですが、ロイヤルペアの対象外です。
    ※両者がロイヤルペアの場合は引き分け。
  • ※「A+9=10(0点)」などは通常の0点扱いとなります。
  • 手札が無くなると、使った13枚を再度シャッフルして勝利数を維持したまま配り直します。
